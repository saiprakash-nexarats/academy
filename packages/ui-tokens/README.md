# @nexarats/ui-tokens
## Enterprise Shared Design Tokens

Authoritative design tokens extracted directly from the Nexarats Academy baseline styling configuration.

### Token Categories
- `colors`: Core brand blues (`#2563EB`, `#1D4ED8`, `#0F1D40`), navy, slate neutrals, and surface backgrounds (`#F8FAFC`, `#FFFFFF`).
- `typography`: Plus Jakarta Sans and Inter font stacks.
- `shadows`: Elevated card, hover glow, and floating panel shadow tokens.
- `borderRadius`: Card (`1rem`), panel (`1.25rem`), and full pill geometries.
- `animation`: Keyframe animations for subtle pulses and slow float effects.

### Usage
This package provides pure JavaScript/TypeScript token definitions for web (Tailwind CSS configuration) and mobile (React Native / NativeWind).
