# @nexarats/api-contracts
## Shared API Contracts & Schemas

This workspace package defines contract schemas and TypeScript types shared between the Spring Boot core backend, web portal clients, and the mobile Expo application.

### Planned Contents (Phase 2+)
- OpenAPI 3.1 specifications generated from Spring Boot backend.
- TypeScript interface definitions for REST payloads and RFC 7807 error objects.
- Zod runtime validation schemas.
